# Open Graph Image Specifications

## Required Images for SEO

Create these images and place them in `/public/` folder:

### 1. **og-image.jpg** (Main homepage)

- Size: 1200 x 630 px
- Content:

  ```
  Background: #fff7f6 (light pink)

  [Henzo Logo]

  Đặt lịch làm đẹp online
  Salon • Spa • Massage • Nail

  Hà Nội & TP. Hồ Chí Minh

  #ff5b5b accent color
  ```

### 2. **og-business.jpg** (Business page)

- Size: 1200 x 630 px
- Content:

  ```
  Background: Gradient from #ff9800 to #ff5b5b

  [Henzo cho Salon Logo]

  Phần mềm quản lý Salon
  MIỄN PHÍ đến 6/2026

  ✓ Đặt lịch online
  ✓ Quản lý khách hàng
  ✓ Nhắc hẹn tự động
  ```

## Quick Create with Canva

1. Go to Canva.com
2. Create custom size: 1200 x 630 px
3. Use template: "Facebook Post"
4. Brand colors:
   - Primary: #ff5b5b
   - Secondary: #ff9800
   - Background: #fff7f6
5. Export as JPG (high quality)
6. Name: og-image.jpg and og-business.jpg

## Test Your Images

After creating, test at:

- https://www.opengraph.xyz/
- https://cards-dev.twitter.com/validator
- Facebook Sharing Debugger

Make sure:

- Images load quickly (< 300KB)
- Text is readable on mobile
- Brand colors match (#ff5b5b)
