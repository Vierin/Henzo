# Структура маршрутов проекта Henzo

## Обзор реструктуризации

Проект был реструктурирован для лучшей организации маршрутов с использованием групп маршрутов Next.js 13+ и AuthGuard для защиты страниц.

## Новая структура маршрутов

```
apps/frontend/src/app/
├── (client)/                    # Группа маршрутов для клиентов
│   ├── layout.tsx              # Layout с AuthGuard для CLIENT
│   ├── dashboard/
│   │   └── page.tsx            # /dashboard - Главная страница клиента
│   ├── history/
│   │   └── page.tsx            # /history - История посещений
│   ├── reviews/
│   │   └── page.tsx            # /reviews - Отзывы клиента
│   └── settings/
│       └── page.tsx            # /settings - Настройки аккаунта
│
├── (owner)/                     # Группа маршрутов для владельцев
│   ├── layout.tsx              # Layout с AuthGuard для OWNER
│   ├── dashboard/
│   │   └── page.tsx            # /dashboard - Панель владельца
│   ├── services/
│   │   ├── page.tsx            # /services - Управление услугами
│   │   └── new/
│   │       └── page.tsx        # /services/new - Создание услуги
│   ├── staff/
│   │   └── page.tsx            # /staff - Управление персоналом
│   └── salon-info/
│       └── page.tsx            # /salon-info - Информация о салоне
│
├── (public)/                    # Группа публичных маршрутов
│   ├── layout.tsx              # Layout с PublicHeader
│   ├── page.tsx                # / - Главная страница
│   ├── salons/
│   │   └── page.tsx            # /salons - Список салонов
│   └── salon/
│       └── [id]/
│           └── page.tsx        # /salon/[id] - Детальная страница салона
│
└── layout.tsx                   # Корневой layout с AuthProvider
```

## Компоненты защиты

### AuthGuard

- **Расположение**: `src/components/AuthGuard.tsx`
- **Функции**:
  - Проверка авторизации пользователя
  - Проверка роли пользователя (CLIENT, OWNER, ADMIN)
  - Редирект неавторизованных пользователей
  - Отображение загрузки во время проверки

### Layout компоненты

- **ClientLayout**: `src/components/ClientLayout.tsx`
  - Используется в группе `(client)`
  - Включает ClientSidebar и PublicHeader
- **OwnerLayout**: `src/components/OwnerLayout.tsx`
  - Используется в группе `(owner)`
  - Включает OwnerHeader
- **PublicLayout**: Встроен в `(public)/layout.tsx`
  - Включает только PublicHeader

## Обновленные маршруты

### Клиентские маршруты (требуют роль CLIENT)

- `/dashboard` - Главная страница клиента (было `/client`)
- `/history` - История посещений (было `/client/history`)
- `/reviews` - Отзывы (было `/client/reviews`)
- `/settings` - Настройки (было `/client/settings`)

### Маршруты владельца (требуют роль OWNER)

- `/dashboard` - Панель владельца (было `/owner`)
- `/services` - Управление услугами (было `/owner/services`)
- `/services/new` - Создание услуги (было `/owner/services/new`)
- `/staff` - Управление персоналом (было `/owner/staff`)
- `/staff/new` - Добавление персонала (было `/owner/staff/new`)
- `/salon-info` - Информация о салоне (было `/owner/salon-info`)

### Публичные маршруты (доступны всем)

- `/` - Главная страница
- `/salons` - Список салонов
- `/salon/[id]` - Детальная страница салона

## Преимущества новой структуры

1. **Четкое разделение ролей**: Каждая группа маршрутов защищена соответствующей ролью
2. **Автоматическая защита**: AuthGuard автоматически проверяет права доступа
3. **Лучшая организация**: Логическое группирование связанных страниц
4. **Упрощенные URL**: Убраны префиксы `/client/` и `/owner/` из URL
5. **Переиспользуемые layout**: Каждая группа имеет свой layout с общими элементами
6. **Масштабируемость**: Легко добавлять новые маршруты в соответствующие группы

## Миграция

Все ссылки в компонентах были обновлены для использования новых маршрутов:

- `ClientSidebar` - обновлены ссылки на клиентские страницы
- `OwnerHeader` - обновлены ссылки на страницы владельца
- Страницы - обновлены внутренние ссылки и редиректы

## Безопасность

- Все страницы клиентов и владельцев защищены AuthGuard
- Автоматический редирект неавторизованных пользователей
- Проверка ролей на уровне маршрутов
- Сохранение состояния авторизации через Zustand store
