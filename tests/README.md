# E2E Tests with Playwright

## Установка

Playwright уже установлен в проекте. Если нужно установить браузеры:

```bash
npx playwright install
```

## Запуск тестов

Перед запуском тестов убедитесь, что:

1. **Frontend сервер запущен:**

   ```bash
   npm run dev
   ```

   Или используйте production build:

   ```bash
   npm run build && npm start
   ```

2. **Backend API доступен:**
   - Убедитесь, что backend запущен на `http://localhost:3001` (или укажите `NEXT_PUBLIC_API_URL` в `.env`)
   - Backend должен быть доступен и работать корректно

3. **Запустите тесты:**

   ```bash
   # Обычный запуск
   npm run test:e2e

   # С UI интерфейсом
   npm run test:e2e:ui

   # В видимом режиме (headed)
   npm run test:e2e:headed

   # В режиме отладки
   npm run test:e2e:debug
   ```

## Тесты

### `client-registration.spec.ts`

Тест регистрации нового клиента:

- Заполняет форму регистрации
- Отправляет данные на сервер
- Проверяет отсутствие ошибок в консоли
- Проверяет отсутствие ошибок сети
- Проверяет успешный редирект после регистрации

**Что проверяется:**

- ✅ Форма загружается корректно
- ✅ Все поля заполняются
- ✅ API запрос отправляется
- ✅ Нет критических ошибок консоли
- ✅ Нет критических ошибок сети (500+)
- ✅ Происходит редирект на `/check-email` или `/dashboard`

## Переменные окружения

Можно задать через `.env` или переменные окружения:

- `NEXT_PUBLIC_FRONTEND_URL` - URL фронтенда (по умолчанию: `http://localhost:3000`)
- `NEXT_PUBLIC_API_URL` - URL бэкенда (по умолчанию: `http://localhost:3001`)

## Результаты тестов

После запуска тестов:

- HTML отчет будет доступен в `playwright-report/index.html`
- Скриншоты ошибок будут в `test-results/`
- Видео ошибок будет в `test-results/`

## Отладка

Если тест падает:

1. Запустите в режиме отладки: `npm run test:e2e:debug`
2. Проверьте логи в консоли
3. Проверьте, что frontend и backend запущены
4. Проверьте, что API доступен и отвечает корректно
